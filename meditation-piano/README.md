## 구성

- 길이: `TARGET_SEC`(기본 180초)에 맞춰 주제 반복 횟수를 코드 단위로 덜어내고, 1칸 미만의 오차는 템포를 ±3% 안에서 조정해 맞춥니다.
- 곡 구조: 도입(화음만) → 주제 A(멜로디) → 전개 B → 주제 A′ → 종결부 → 으뜸화음 종지
- 멜로디: 코드마다 하나의 프레이즈(리듬+윤곽)를 만들어 반복하되, 두 번째부터는 음정을 조금씩 바꿔 변주합니다. 강박과 긴 음은 코드 구성음에 놓입니다.
- 음색: 부분음 합성 피아노(현의 비조화성, 세 현의 맥놀이, 해머 타격음) + 4.5초 홀 리버브

## 파일

- `audio/*.mp3` — 감상용 음원 (128 kbps, 스테레오)
- `midi/*.mid` — DAW에서 가상악기로 다시 녹음하거나 악보로 볼 수 있는 MIDI
- `player.html` — 호흡 안내 원이 있는 브라우저 플레이어 (`audio/` 폴더와 같은 위치에서 열기)
- `compose.py` — 작곡·렌더링 스크립트 (시드가 고정되어 있어 같은 결과가 다시 나옵니다)

```bash
pip install numpy scipy mido lameenc
python3 compose.py          # 10곡 전체 생성
python3 compose.py 3 7      # 3번, 7번만 다시 생성
```

곡마다 `TRACKS`의 조성(`key`, `scale`), 템포(`bpm`), 화성 진행(`prog`), 섹션 구성(`sections`)을 바꾸면 새 곡을 만들 수 있습니다.
